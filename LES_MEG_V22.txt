FiskeDex v22 – profilbilder

1. Last opp alle filene til GitHub Pages som vanlig.
2. Åpne Supabase > SQL Editor > New query.
3. Åpne filen fiskedex_v22_profilbilder.sql fra denne pakken, lim inn og trykk Run.
4. I FiskeDex: åpne Profiler, velg fisker og trykk på kameraet ved profilbildet.

Profilbildet blir komprimert automatisk før lagring. Gjester kan se bildene, men ikke endre dem.
